# 專案列表與看板回應性規格

## 專案列表顯示進行中任務

- `GET /api/projects` 的每個專案項目應提供 `activeTasks`，僅包含仍有效、已進入 Flow，且狀態為 `active` 的任務。
- 任務摘要應包含 `id` 與 `title`，並依看板排序順序輸出。
- 專案列表的專案卡片應在有進行中任務時顯示「進行中：<任務標題>」。

## 冷啟動載入

- RonFlow session 啟用完成後，專案/看板載入與邀請收件匣計數應並行發出。
- 任一個次要摘要查詢較慢時，不應阻塞另一個查詢的完成與畫面呈現。

## 任務狀態變更

- 任務狀態變更成功後，既有看板內容必須維持可見。
- 後續同步應使用不清空既有資料的靜默重新整理，避免看板短暫變成載入畫面。
- 若同步失敗，先前看板資料保留，並維持既有的命令錯誤處理方式。
